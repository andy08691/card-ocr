# ─────────────────────────────────────────────────────────────────────────────
# card_ocr 應用層依賴（不含 OCR 引擎）
#
# OCR 引擎改用 MinerU（OpenDataLab），因其自帶 torch / numpy / opencv / pillow
# 等重量級套件並有自己的版本鎖定，故「不」寫在這裡，而是「另外」安裝，
# 避免版本衝突。安裝順序見 README「安裝步驟」：
#
#   1) 建立 venv（Python 3.10–3.13）
#   2) 安裝 MinerU：
#        macOS (Apple Silicon)：  uv pip install -U "mineru[mlx]"
#        Linux + GPU：            uv pip install -U "mineru[vllm]"   # 或 mineru[all]
#        純 CPU：                 uv pip install -U "mineru[core]"
#   3) 下載模型：  mineru-models-download -s huggingface -m vlm
#   4) 安裝本檔：  uv pip install -r requirements.txt
# ─────────────────────────────────────────────────────────────────────────────
